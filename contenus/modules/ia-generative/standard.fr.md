## Un outil utile… qui n'oublie rien

Les assistants d'IA générative (agents conversationnels, générateurs d'images, outils de traduction ou de résumé) font gagner du temps. Mais tout ce que vous y saisissez **quitte votre poste** : selon le service, ces données peuvent être conservées, lues par l'éditeur ou réutilisées pour entraîner le modèle.

## Les trois règles d'or

1. **Utiliser les outils autorisés** par {{organisation.nom}}. Un service grand public gratuit, même très connu, n'offre pas les mêmes garanties qu'un outil encadré par un contrat. Utiliser un outil non validé, c'est de l'**informatique fantôme** (*shadow IT*).
2. **Ne jamais saisir** d'informations sensibles dans un outil non autorisé.
3. **Vérifier** toute réponse : l'IA peut inventer des faits, des références ou du code vulnérable, avec beaucoup d'aplomb.

## Je peux / je ne peux pas saisir

| Je peux, dans un outil autorisé | Je ne saisis jamais dans un outil non autorisé |
| --- | --- |
| Un texte public à reformuler | Des données personnelles (clients, patients, salariés) |
| Une question générale | Des contrats, devis, données financières |
| Un modèle de document anonymisé | Des mots de passe, clés d'API, configurations techniques |
| | Du code source propriétaire |
| | Des comptes rendus de réunions confidentielles |

> **À retenir** : si vous ne publieriez pas l'information sur un site public, ne la collez pas dans une IA non autorisée.

## L'IA au service des attaquants

Les attaquants utilisent aussi l'IA :

- messages d'hameçonnage **parfaitement rédigés** et personnalisés ;
- **voix et vidéos clonées** pour les fraudes (voir le module Fraude au président) ;
- faux documents, fausses factures, faux profils très crédibles ;
- « injection de consignes » (*prompt injection*) : un document ou une page web piégés peuvent donner des ordres cachés à votre assistant d'IA.

## Pour les managers et les administrateurs

- **Managers** : clarifiez avec vos équipes quels outils sont autorisés et pour quels usages ; un interdit sans alternative pousse au contournement.
- **Administrateurs** : évaluez un outil d'IA avant son intégration (hébergement et localisation des données, conservation, réutilisation pour l'entraînement, droits d'accès aux sources connectées, journalisation). Ne connectez pas un assistant à des données plus larges que nécessaire.
