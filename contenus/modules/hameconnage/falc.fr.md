## De quoi on parle ?

Des pirates envoient de faux messages.
Ces messages ressemblent à des vrais messages.

Ils arrivent :

- par e-mail,
- par SMS,
- avec un QR code.

Un QR code est un petit carré noir et blanc.
On le prend en photo avec son téléphone.
Il ouvre un site internet.

Les pirates veulent :

- voler votre mot de passe,
- voler de l'argent,
- abîmer les ordinateurs.

## Comment reconnaître un faux message ?

Faites attention si le message :

- vous demande d'aller **très vite**,
- vous fait **peur**,
- vous demande votre **mot de passe**,
- vous demande de **payer**,
- vous promet un **cadeau**.

Attention : un faux message peut être très bien écrit.
Il peut ne pas avoir de fautes.
