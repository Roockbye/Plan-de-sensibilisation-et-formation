## Pourquoi c'est important

L'hameçonnage (*phishing*) est la porte d'entrée de la plupart des cyberattaques. Un seul clic sur un lien piégé peut suffire à voler un mot de passe, installer un logiciel malveillant ou déclencher un rançongiciel.

Les attaquants ne se limitent plus à l'e-mail :

- **par SMS** (*smishing*) : faux colis, fausse amende, faux remboursement ;
- **par messagerie instantanée** ou réseaux sociaux ;
- **par QR code** (*quishing*) : l'adresse du site n'est pas visible avant le scan, ce qui contourne les filtres de messagerie ;
- **avec l'IA générative** : les messages frauduleux sont désormais sans fautes, personnalisés et rédigés dans un français parfait. L'absence de fautes n'est **plus** un signe de confiance.

## Les indices qui doivent alerter

| Indice | Exemple |
| --- | --- |
| L'urgence ou la menace | « Votre compte sera supprimé dans 24 h » |
| Une demande inhabituelle | Saisir son mot de passe, payer des frais, ouvrir une pièce jointe inattendue |
| Un expéditeur approximatif | `support@{{organisation.domaine}}-securite.com` au lieu de `@{{organisation.domaine}}` |
| Un lien dont la destination diffère du texte | Le texte affiche une adresse connue, le lien mène ailleurs |
| Une formule générique | « Cher utilisateur », « Cher client » |
| Une offre trop belle | Gain, remboursement, cadeau inattendu |

> **À retenir** : un seul indice suffit pour douter. En cas de doute, on ne clique pas, on vérifie par un autre moyen et on signale.

## Vérifier un lien sans cliquer

1. **Sur ordinateur** : survolez le lien avec la souris, ou faites un clic droit puis « Copier l'adresse du lien », et lisez l'adresse complète.
2. **Sur mobile** : appuyez longuement sur le lien pour afficher l'adresse sans l'ouvrir.
3. **Lisez le domaine de droite à gauche** à partir du premier `/` : dans `https://{{organisation.domaine}}.connexion-verif.co/login`, le vrai domaine est `connexion-verif.co`, pas `{{organisation.domaine}}`.

## Les QR codes

Un QR code n'est qu'un lien caché. Avant de scanner :

- demandez-vous **qui** a placé ce QR code (un autocollant collé sur une affiche officielle est suspect) ;
- après le scan, **lisez l'adresse proposée** avant de l'ouvrir ;
- ne saisissez jamais vos identifiants professionnels sur une page ouverte depuis un QR code reçu par e-mail.

Signaler un message suspect n'est **jamais** une perte de temps, même si vous n'êtes pas sûr. Chez {{organisation.nom}}, utilisez {{contacts.signalement}}.
