## Pourquoi protéger son mot de passe ?

Votre mot de passe ouvre votre compte.
Un pirate qui a votre mot de passe peut entrer dans votre compte.

## Comment faire un bon mot de passe ?

Faites une **phrase de passe**.
Une phrase de passe, c'est plusieurs mots à la suite.

Exemple : `Girafe-Cadenas-Violon-Marée`

Choisissez des mots au hasard.
N'utilisez pas :

- le nom de votre enfant,
- le nom de votre animal,
- votre date de naissance.

## Un mot de passe différent pour chaque compte

Utilisez un mot de passe différent pour chaque site.
Si un site se fait voler vos mots de passe,
vos autres comptes restent protégés.

Il y a beaucoup de mots de passe à retenir.
Un **gestionnaire de mots de passe** peut les retenir pour vous.
Demandez lequel utiliser à {{contacts.securite}}.

## La double authentification

Parfois, votre téléphone vous demande de valider une connexion.

- Vous êtes en train de vous connecter ? Vous pouvez valider.
- Vous n'êtes **pas** en train de vous connecter ? Appuyez sur **Refuser**.
  Puis prévenez l'équipe sécurité.

Ne donnez jamais le code reçu sur votre téléphone.
Même si la personne dit qu'elle travaille au service informatique.

> **À retenir** : une phrase de passe longue. Un mot de passe différent pour chaque site. Je ne donne jamais mon mot de passe ni mon code.
