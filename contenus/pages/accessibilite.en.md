## Measures in place

- Full keyboard navigation, skip links, always-visible focus.
- Heading structure and page regions (header, navigation, content, footer) for screen readers.
- Contrast of at least 4.5:1: the organisation's colours are **checked automatically** each time the site is generated and corrected if needed.
- No information conveyed by colour alone: every status is also shown as text.
- No time limit in quizzes and scenarios.
- **Easy-read version** of every module.
- Display preferences: text size up to 200 %, fonts for low vision or dyslexia, increased text spacing, dark theme, high contrast, reduced motion.
- Text transcript and captions for any audio or video content.
- Dashboard charts always accompanied by a data table.
- Automated tests (axe-core) of every page on each code change.

## Non-accessible content

- Interactive activities (quizzes, scenarios) require JavaScript. The learning content of each module remains available without JavaScript.
- Some modules are not yet translated into English and are shown in French (marked as such for screen readers).
- A full manual audit with screen readers (NVDA, VoiceOver) remains to be carried out: the compliance status will be updated afterwards.

## Technologies used

HTML5, CSS, JavaScript (progressive enhancement), WAI-ARIA where needed.

## Test environment

Automated tests: axe-core via Playwright (Chromium). Recommended manual checks: NVDA with Firefox (Windows), VoiceOver with Safari (macOS, iOS), keyboard only, 200 % zoom.
